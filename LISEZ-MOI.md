# Cap — ton conseiller budget

Appli privée (PWA) : tes données restent sur ton téléphone.

## Mise en ligne sur GitHub Pages (5 min)
1. github.com > New repository > nom `cap` (un dépôt public suffit : seul le code est visible, jamais tes données).
2. « uploading an existing file » : glisse TOUT le contenu de ce dossier (index.html à la racine, pas dans un sous-dossier), puis Commit.
3. Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)` > Save.
4. Après ~1 minute : https://TON-PSEUDO.github.io/cap/

## Installation sur Android
Ouvre l'adresse dans Chrome > menu ⋮ > « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
Au premier lancement, crée ton code PIN à 4 chiffres.

## À savoir
- Sauvegarde : Gérer > Sauvegarde > Exporter (surtout avant de changer de téléphone ou de vider les données de Chrome).
- IA optionnelle : clé Gemini gratuite sur aistudio.google.com/apikey, à coller dans Gérer > IA Gemini.
- Mise à jour de l'appli : remplace les fichiers sur GitHub ; ferme et rouvre l'appli deux fois.

## RevPoints
L’onglet « Points » suit ton objectif (60 000 → 100 000). Les astuces en direct utilisent la même clé Gemini gratuite que le conseiller (Gérer › IA Gemini). Après mise à jour, ferme et rouvre l’appli deux fois pour que le nouveau cache (cap-v2) s’installe.
